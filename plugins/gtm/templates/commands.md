# Command map

> One line per GTM skill: the command and what it does. The `gtm` skill's advisor reads it to
> propose the next command.

- `/gtm:init` · set up the GTM root: brief, config, team settings, guidelines
- `/gtm:gtm` · pick the track and route, or propose the next command
- `/gtm:brainstorm` · explore a vague idea with the team into a note the spec cites
- `/gtm:design` · draw and score mockups, then show them for approval
- `/gtm:spec` · write the spec and present its summary for approval
- `/gtm:plan` · write the task plan from an approved spec
- `/gtm:deliver` · run the plan's tasks with reviews, then the final review
- `/gtm:ship` · gate, PR text, then push, merge, tag or release on the human's go
- `/gtm:retro` · turn a shipped branch into lessons and guideline proposals
- `/gtm:brief-me` · re-present an artifact at another detail level, or dig into it
- `/gtm:status` · show where the current run stands
- `/gtm:pause` · stop the run cleanly and write how to resume it
- `/gtm:tune` · re-tune team settings from the ledger, as decision cards
