# Copy guideline

> When to read: designer, implementer and reviewer when a diff changes user-facing text.

## Rules
- Plain words, sentence case, the user's own language; one term per concept, everywhere.
- Never a word that judges the user.
- Every language the product ships is updated in the same commit.
- A button says what it does; a link or button's visible text is part of its accessible name.
- <Project rule: tone, address form, typography, glossary.>
