# Accessibility guideline

> When to read: designer, design critic, implementer and reviewer on UI tasks, ux-qa always.

Accessibility is a rule, not polish: a failure is an important finding.

- **Level:** WCAG <2.2 AA>.
- **Targets:** at least 44 × 44 px.
- **Contrast:** text 4.5:1, large text and meaningful graphics 3:1, in light and dark.
- **Keyboard:** every action reachable and visible on focus; no trap; logical order.
- **Names:** every control has an accessible name that contains its visible text.
- **Meaning never by colour alone.** Motion respects reduced-motion settings.
- **Checked by:** automated checks (e.g. axe) per screen and theme, plus <manual check>.
